Sizzle Line: a one-cook kitchen rush for a desktop browser, mouse only. Pick an order ticket, chop at
the board or cook at the stove in the order its recipe asks for, then pass the finished plate through
the service window before the ticket burns. Plain 2D canvas, no libraries, no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
